# 🏆 RHHS Classroom Champion

**A comprehensive environmental classroom management and evaluation system designed to promote sustainability and recognize excellence in eco-friendly practices.**

---

## 📖 Overview

RHHS Classroom Champion is a web-based platform that empowers schools to track, evaluate, and celebrate environmental initiatives across classrooms. The system provides a structured framework for assessing classroom sustainability efforts, managing eco-friendly practices, and fostering healthy competition through division-based leaderboards.

Built for educational institutions committed to environmental stewardship, this application streamlines the evaluation process while providing real-time insights into sustainability performance across different classroom divisions.

---

## ✨ Key Features

### 🎯 **Classroom Evaluation System**
- **Dynamic Checklist Management**: Customizable evaluation criteria for assessing environmental practices
- **Flexible Scoring**: Configurable point values for different sustainability metrics
- **Real-time Evaluations**: Supervisors can conduct and submit evaluations instantly
- **Historical Tracking**: Complete evaluation history with date-stamped records
- **Score Analytics**: Detailed breakdowns of total scores vs. maximum possible scores

### 📊 **Division-Based Leaderboards**
- **Multi-Division Support**: Separate leaderboards for different classroom divisions
- **Live Rankings**: Real-time updates as new evaluations are submitted
- **Performance Metrics**: Average scores, total evaluations, and ranking positions
- **Competitive Insights**: Visual representation of classroom standings

### 👥 **Role-Based Access Control**

The system supports four distinct user roles, each with specific permissions:

#### **Super Admin**
- Full system access and control
- User management (create, edit, deactivate users)
- Classroom management (create, edit, delete classrooms)
- Checklist item management
- Data management (archive, restore, delete)
- Access to all statistics and analytics
- System-wide configuration

#### **Admin**
- Classroom and checklist management
- User management capabilities
- Evaluation oversight
- Access to statistics and reports
- Data archiving and management

#### **Supervisor**
- Conduct classroom evaluations
- View assigned classrooms
- Access evaluation forms
- Submit scores and assessments
- View evaluation history

#### **Viewer**
- Read-only access to leaderboards
- View classroom rankings
- Access public statistics
- Monitor overall performance trends

### 🗂️ **Comprehensive Data Management**

#### **Archive System**
- **Selective Archiving**: Archive individual evaluations or bulk selections
- **Restore Capability**: Retrieve archived data when needed
- **Archive Browser**: Searchable archive with filtering options
- **Historical Preservation**: Maintain complete records across evaluation periods

#### **Bulk Operations**
- **Archive & Reset**: End-of-period archiving with system reset
- **Batch Selection**: Multi-select functionality for efficient management
- **Smart Search**: Filter evaluations by classroom, grade, supervisor, or date

#### **Controlled Data Management**
- **Record Management**: Administrative ability to review and update evaluation records
- **Classroom Lifecycle**: Manage classroom participation across divisions and academic terms
- **Safety Confirmations**: Multi-step confirmation dialogs prevent accidental data loss

## 🏫 **How It Works**

### **For Supervisors**
1. **Log in** to your supervisor account
2. **Navigate** to the Evaluate tab
3. **Select** a classroom from your assigned list
4. **Complete** the evaluation checklist
5. **Submit** scores and view instant feedback

### **For Admins**
1. **Manage** classrooms and assign them to divisions
2. **Configure** checklist items and point values
3. **Oversee** evaluations and monitor submissions
4. **Generate** reports and analyze performance
5. **Archive** data at the end of evaluation periods

### **For Viewers**
1. **Access** the public leaderboard
2. **View** rankings across divisions
3. **Track** classroom performance over time
4. **Monitor** sustainability progress
